NDVR+IBF (from Pathvector_v2)
====

NDVR (NDN Distance Vector Routing) is multipath routing protocol for NDN by Italo Valcy. This is a pathvector implementation. Because the pathvector handling a lot data on named-data network, we are using an inversible bloom filter IBF
to save data storage and memory. So, NDVR+IBF (Italo Valcy+Fábio Santos) is a slim pathvector multipath routing protocol.
